# 사용 설명서

앱은 탭 네 개로 이루어져 있습니다: **⚙️ 설정**, **🌐 hwa.moe**, **🎵 내 곡**, **📦 XAPK**.

## ⚙️ 설정

모드 게임의 `config.txt`를 바꿉니다. 토글을 바꾸면 **즉시 저장**되고, 게임은 1초마다 파일을 확인해 플레이 중에도 바로 반영합니다.

| 토글 | config.txt 키 | 기본값 | 효과 |
|---|---|---|---|
| 오토플레이 | `오토플레이` | 끔 | 차트를 자동으로 연주합니다. |
| 강제퍼펙트 | `강제퍼펙트` | 켬 | 모든 타격 판정을 Perfect로 올립니다. |
| 피버충전금지 | `피버충전금지` | 끔 | 피버 게이지가 차지 않게 막습니다. |
| 시네마 | `시네마` | 켬 | 커스텀 곡의 BGA 비디오(`.mp4`)를 재생합니다. |
| 고스트노트보이기 | `고스트노트보이기` | 켬 | 고스트 노트가 투명해지지 않게 합니다. 공식 곡과, `info.txt`에 고스트 설정이 없는 커스텀 곡에 적용됩니다. `info.txt`에 `커스텀 곡 고스트 보이기`가 적힌 곡은 그 값을 따릅니다. |

하단 버튼:

- **🔄 새로고침**: 파일에서 설정을 다시 읽습니다. PC나 파일 관리자로 `config.txt`를 직접 고쳤을 때 씁니다.
- **⚡ 기본값**: 위 표의 기본값으로 되돌리고 바로 저장합니다.
- **💾 설정 저장**: 수동으로 다시 저장합니다. 저장 결과를 토스트로 알려줍니다.

맨 위 연동 표시:

- 🔗 **게임 연동됨**: 게임이 이 설정 파일을 읽을 수 있는 상태입니다.
- ⚠️ **게임이 설정 파일을 읽을 수 없습니다**: 저장은 됐지만 게임에는 반영되지 않습니다. [설치 가이드 3번](INSTALL.md#3-게임-설정-연동-android-11-이상-기기당-1회)을 따라 주세요.

### config.txt 직접 편집

파일 위치는 `/storage/emulated/0/MuseDash/config.txt`입니다.
비서 앱은 저장할 때 위 다섯 줄만 바꾸고, 그 밖의 줄(주석, 지연·오프셋 같은 다른 키)은 그대로 둡니다.

> 파일을 **지우거나 새로 만들지 마세요.** 내용을 고치는 것은 괜찮지만, 지우고 새로 만들면 게임 연동이 풀립니다.

## 🌐 hwa.moe

[hwa.moe](https://hwa.moe)에 올라온 커스텀 앨범을 둘러보고 설치합니다.

- **⬇️ 주입**: 곡을 받아 `/MuseDash/hwa/<곡 폴더>/`에 풀어 넣습니다. 게임은 **다음에 시작할 때** 이 곡을 자기 폴더로 가져갑니다.
- **✅ 설치됨**: 이미 기기에 있는 곡입니다.
- **🗑️**: 곡을 지웁니다. 지우면 다시 **⬇️ 주입**으로 바뀝니다.
- **🔄 새로고침**: 목록을 다시 받아옵니다.

## 🎵 내 곡

기기에 설치된 커스텀 곡 목록과 곡별 정보(BMS, BGM, 자켓)를 보여줍니다.

- **🗑️ 삭제**: 공용 폴더에서 지웁니다. 게임 폴더의 사본은 게임이 다음에 시작할 때 함께 지워집니다.
- **▶ 뮤즈대시 모드 실행하기**: 모드 게임을 실행합니다. 게임에 곡을 가져갈 권한도 이때 다시 줍니다.

### 곡이 게임에 들어가는 방식

Android 11 이상에서는 비서 앱이 게임 폴더에 쓸 수 없고, 게임도 비서 앱이 받은 파일을 직접 읽을 수 없습니다. 그래서 다음 순서로 동작합니다.

1. 비서 앱은 받은 곡을 공용 폴더 `/MuseDash/hwa/`에 둡니다.
2. 비서 앱은 이 폴더를 **읽기 전용으로, 게임에게만** 열어 둡니다.
3. 게임이 시작되면 모드가 목록을 받아, 새 파일이나 크기가 바뀐 파일만 게임 폴더로 복사합니다.
4. 비서 앱에서 지운 곡은 게임 폴더에서도 지웁니다. 단 모드가 비서 앱에서 가져온 곡만 지우고, adb로 직접 넣은 곡은 그대로 둡니다.

그래서 곡을 받거나 지운 뒤에는 **게임을 완전히 껐다 켜야** 반영됩니다.

## 📦 XAPK

내장 저장소 최상위, `Download/`, `MuseDash/` 폴더에서 `.xapk`, `.apk` 파일을 찾아 보여줍니다. 뮤즈대시 관련 파일은 강조 표시됩니다.

- `.apk`: 시스템 설치 화면을 바로 엽니다.
- `.xapk`: 안의 `.obb`를 `/Android/obb/<패키지>/`(뮤즈대시 모드는 `com.prpr.musedash.mod`)에 풀어 넣은 뒤, 안의 APK로 설치 화면을 엽니다.
  - 처음 한 번은 **'출처를 알 수 없는 앱 설치' 허용**이 필요합니다. 허용하지 않았으면 [설치]를 눌렀을 때 그 설정 화면이 열립니다. 허용하고 돌아와 [설치]를 다시 누르세요. (Android 11 이상은 이 허용이 있어야 다른 앱의 OBB 폴더에 쓸 수 있습니다.)
  - 보존 아카이브 XAPK(약 4.4 GB)는 OBB를 푸는 데 몇 분 걸립니다. "OBB 배치 중" 알림이 뜨고, 다 풀리면 설치 화면이 열립니다. 폰에 여유 공간이 약 11 GB(XAPK 4.4 + OBB 4.3 + 첫 실행 때 풀리는 캐시 2.2) 필요합니다.
  - 같은 XAPK를 다시 설치하면 이미 들어 있는 같은 크기의 OBB는 건너뜁니다.
