# 곡 폴더와 info.txt 규칙

커스텀 곡 폴더 하나가 게임에서 어떻게 읽히는지 정리했습니다. 비서 앱의 **🎵 내 곡** 탭은 v2.2.0부터 게임 모드(`mod.js`)와 **같은 규칙**으로 곡을 읽습니다. 그래서 앱에 보이는 제목·레벨·경고가 게임에서 보게 될 것과 같습니다.

> 규칙의 원본은 게임 모드 소스 `src/hwa/manifest.ts`(info.txt 읽기), `src/hwa/chartFiles.ts`(채보 고르기), `src/hwa/library.ts`(파일 고르기)입니다. 앱 쪽 사본은 `songs/HwaManifest.java`, `songs/ChartFiles.java`, `songs/SongInfo.java`입니다.

## 1. 폴더 모양

```
/storage/emulated/0/MuseDash/hwa/
 └── <곡 폴더>/
      ├── info.txt        곡 정보 (이름은 아래 규칙대로 골라짐)
      ├── hwa2.bms        채보 (하나 이상)
      ├── easy.bms        난이도별 채보 (선택)
      ├── music.ogg       음악
      ├── cover.png       자켓
      └── bga.mp4         배경 영상 (선택)
```

- 게임은 곡 폴더 **바로 아래 파일만** 봅니다. ZIP을 풀었더니 `곡 폴더/곡 폴더/info.txt`처럼 한 단계 더 들어가 있으면 곡이 안 보입니다.
- 이름이 `.`으로 시작하는 폴더(받는 중인 `.dl_…`, 지우는 중인 `.del_…`)는 앱과 게임 모두 건너뜁니다.

## 2. 게임이 파일을 고르는 방법

| 무엇 | 고르는 규칙 |
|---|---|
| info 파일 | `info.txt` 또는 `info1.txt`(대소문자 무시). 없으면 이름순으로 **첫 번째 `.txt`** — `hwa info.txt`, `readme.txt`도 info 파일로 읽힙니다. |
| 기본 채보 | 편집기 임시본을 뺀 `.bms` 중 `chart.bms`·`main.bms`·`test.bms`가 먼저, 없으면 이름순 첫 번째. 난이도별로 지정한 채보는 먼저 빼고 고릅니다. |
| 편집기 임시본 | `~`·`___`·`.`으로 시작하거나 `~`로 끝나는 파일, 이름이 `temp`·`tmp`이거나 `temp_1`·`tmp-2`처럼 그 뒤에 글자가 아닌 것이 오는 파일. `tempo.bms`는 임시본이 아닙니다. |
| 음악 | `music.ogg`·`music.wav`·`music.mp3`, 없으면 아무 `.ogg`. **`song.mp3` 같은 다른 이름의 mp3·wav는 쓰지 않습니다.** |
| 자켓 | `cover.png`·`cover.jpg`·`cover.jpeg`만 (`cover2.png`는 안 됨). |
| 배경 영상 | `video`·`bga`·`bg`·`movie` + `.mp4`, 없으면 아무 `.mp4`. |

**게임이 곡을 건너뛰는 경우** (앱에 빨간 **게임에 안 보임** 표시):

- info 파일(`.txt`)이 하나도 없을 때
- 임시본이 아닌 `.bms`가 하나도 없을 때

앱 목록에는 이런 곡도 보여 줍니다. 지우거나 고칠 수 있게 하려는 것입니다.

## 3. info.txt 읽는 방법

- 한 줄에 `키 = 값` 하나. 구분자는 그 줄에서 **처음 나오는** `=`, `:`, `：`입니다. 그래서 `title: Re:Zero`의 값은 `Re:Zero`입니다.
- `//`로 시작하는 줄은 주석입니다. 줄 중간의 `//`는 **앞에 공백이 있을 때만** 주석입니다(`https://…`는 그대로 남음).
- 키는 공백과 기호(`- _ / · . ( ) [ ]`)를 빼고 소문자로 만든 뒤, 아래 표의 낱말이 **들어 있으면** 그 항목으로 봅니다. 위에서부터 차례로 보고 처음 맞는 것 하나만 씁니다.
- 영어 제목의 `you ' re`, `don ’ t` 같은 띄어진 축약형은 `you're`, `don't`로 붙여 읽습니다.

### 키 목록 (확인 순서대로)

| 순서 | 항목 | 키에 들어 있으면 | 값 |
|---|---|---|---|
| 1 | 난이도별 채보 | `난이도N bms`, `난이도N 채보`, `difficultyN bms`, `difficultyN chart` (N = 1~5) | 곡 폴더 안 `.bms` 파일 이름. `null`이면 지정 안 함 |
| 2 | 고스트 노트 보이기 | `고스트노트보이기`, `고스트보이기`, `노트보이기`, `ghostnote` | 켜기/끄기 |
| 3 | 오토플레이 | `오토플레이`, `오토`, `autoplay`, `auto` | 켜기/끄기 |
| 4 | 시네마 | `시네마`, `bga`, `video`, `cinema`, `배경영상` | 켜기/끄기 |
| 5 | 피버충전금지 | `피버충전금지`, `피버차단`, `피버금지`, `blockfever`, `nofever` | 켜기/끄기 |
| 6 | 권장표(dt 보정) | `권장표`, `권장dt`, `dt보정`, `recommendeddt`, `fixdt` | 켜기/끄기 |
| 7 | 크리스마스 배경 | `크리스마스`, `christmas`, `xmas` | 켜기/끄기 |
| 8 | 앨범 | `가져올앨범`, `앨범`, `album` | 글자 |
| 9 | 숙주 곡 uid | `uid` (`내가 가져올 uid`) | 예: `0-4` |
| 10 | 커스텀 아티스트 | `커스텀아티스트`, `customartist`, `customauthor` | 글자 |
| 11 | 레벨 디자이너 | `레벨디자이너`, `leveldesigner` | 글자 |
| 12 | 아티스트 | `artist`, `아티스트`, `author` | 글자 |
| 13 | 커스텀 곡 제목 | `커스텀곡제목`, `커스텀곡이름`, `커스텀곡명`, `customsongtitle`, `customsongname`, `customtitle` | 글자 |
| 14 | 곡 이름 | `곡이름`, `곡명`, `곡제목`, `가져올곡`, `song`, `title`, `music` | 글자 |
| 15 | 씬 번호 | `씬번호`, `scene` | 정수 |
| 16 | 난이도 레벨 | `난이도1`~`난이도5`, `difficulty1`~`difficulty5` | 정수. `0`이나 `null`이면 그 난이도 없음 |
| 17 | 안드로이드 지연 | `androiddelay`, `안드로이드delay`, `안드로이드지연` | 숫자(초) |
| 18 | 지연 | `delay`, `지연` | 숫자(초). PC용 값이라 안드로이드에서는 기본으로 쓰지 않습니다 |
| 19 | 오프셋 | `offset`, `오프셋`, `싱크` | 숫자 |

- **켜기/끄기 값**: `활성화`·`켜기`·`켜짐`·`true`·`on`·`yes`·`1` / `비활성화`·`끄기`·`끔`·`false`·`off`·`no`·`0`. 그 밖의 값은 **적지 않은 것**과 같습니다(전역 설정을 따름).
- 어느 항목에도 맞지 않는 키는 게임이 무시합니다. 앱은 **게임이 모르는 info.txt 항목**으로 알려 줍니다(오타 찾기용).

### "들어 있으면" 규칙 때문에 생기는 함정

- `music file = x.ogg`처럼 키에 `music`·`song`·`title`이 들어가면 **곡 이름**으로 읽힙니다.
- 키에 `auto`가 들어가면 오토플레이, `video`·`bga`가 들어가면 시네마로 읽힙니다.
- `christmas scene`은 씬 번호가 아니라 크리스마스 배경입니다(크리스마스를 먼저 봄). `android delay`도 `delay`보다 먼저 봅니다.
- `난이도1 bms`는 레벨(`난이도1`)보다 먼저 봅니다. 그래서 레벨 줄과 채보 줄을 같이 적어도 섞이지 않습니다.

## 4. 앱과 게임에 보이는 것

| 앱 표시 | 뜻 |
|---|---|
| 제목 | `커스텀 곡 제목` → `곡 이름` → 폴더 이름 순. 게임 곡 목록의 제목과 같습니다. |
| 아티스트 | `커스텀 아티스트` → `아티스트`. 둘 다 없으면 앱은 `Custom`으로 씁니다. |
| `Lv 3 · 5` (초록) | 값이 있는 난이도의 레벨. |
| `BMS n` | 임시본을 뺀 채보 수. |
| `난이도별 채보 n` | `난이도N bms`로 지정했고 파일을 찾은 난이도 수. |
| `BGM` / `BGA` | 게임이 고르는 음악 / 배경 영상이 있음. |
| `🎄 크리스마스` | 이 곡은 5번 씬 배경·보스가 크리스마스 판입니다. |
| `곡 설정: …` | info.txt에 적힌 곡별 설정(아래 우선순위). |
| 빨간 글씨 | 게임이 이 곡을 건너뛰는 이유. |
| 주황 글씨 | 곡은 들어가지만 확인할 것: 난이도별 채보를 못 찾음(기본 채보로 대신), 음악 없음, 게임이 모르는 항목. |

### 곡 설정과 전역 설정(설정 탭)의 우선순위

| 항목 | 규칙 |
|---|---|
| 오토플레이, 피버충전금지 | 전역 **또는** 곡 — 어느 한쪽이라도 켜면 켜짐. 곡에서 `끔`으로 적어도 전역이 켜져 있으면 켜짐. |
| 시네마 | 전역 **그리고** 곡 — 곡에서 `끔`이면 그 곡은 꺼짐. |
| 고스트 노트 보이기 | 곡에 값이 있으면 **곡 값**, 없으면 전역. |
| 권장표 | 곡에만 있습니다. |
| 크리스마스 배경 | 커스텀 곡은 곡 값만 봅니다. 설정 탭의 **강제크리스마스**는 공식 곡에만 적용됩니다. |

게임은 판(배틀)을 시작할 때마다 곡의 info.txt를 다시 읽습니다. 다만 게임이 읽는 것은 **게임 폴더에 복사된 사본**이고, 공용 폴더에서 사본으로 가져오는 것은 게임을 시작할 때뿐입니다. 공용 폴더(`/MuseDash/hwa/`)의 info.txt를 고쳤다면 게임을 완전히 껐다 켜야 합니다.

## 5. 비서 앱이 다루지 않는 것

- **커스텀 Spine 스킨**: 게임 폴더 `files/skin test/{character|note}/<세트>/<세트>.json·.atlas·.png`에 둡니다. 비서 앱은 곡(`hwa/`)만 게임에 넘기고 스킨 파일은 옮기지 않으므로 PC에서 adb로 넣습니다. 앱은 켜고 끄는 토글(**커스텀 스킨**)만 있습니다.
- **커스텀 앨범 아이콘** `hwa_tag_icon.png`: 앱이 건드리지 않습니다.
